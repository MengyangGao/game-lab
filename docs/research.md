# 玩法研究与选型

本轮先核对原作实机画面、公开玩法说明和玩家攻略，再确定浏览器中的规则与操作。重点不是借用原作角色或贴图，而是让熟悉原作的玩家能辨认机关、理解目标，并以相近的操作顺序完成谜题。项目中的场景、关卡、文字、图形与程序均独立制作。

## 规则校准

| 参考机制 | 核对到的核心体验 | Game Lab 的实现 |
| --- | --- | --- |
| 匣里流光 | 激发器持续发出光线，承接器改变方向，后续关卡包含可移动机关与多个目标 | 使用「激发器／承接器／建木花枝」术语；镜面旋转后实时重算并显示光路，不再通过抽象圆点和试射按钮判断结果。固定发射端与承接器位置是浏览器短局的简化。 |
| 溢彩画 | 点击右侧列表选色，再点击左侧画框；颜色向四邻同色格扩散，画作有步数限制 | 严格采用先选色、再涂色的操作顺序；画框、纵向颜料列表、扩散过渡和目标色均保留。 |
| 庸人的容器 | 推开军械箱，接近并营救受困者；箱子不能拉回 | 使用雅利洛风格石台、军械箱与原创人形角色；保留推箱重量感和逐步营救路线。 |
| 枘凿六合·Remake | 在既有结构周围搭建资源块，补全目标立体 | 使用金属资源块、可旋转立体视角与即时投影校准；固定块不能移除，空投影线上不能多放。 |
| 筑梦拼图 | 移动散落画片，使线条和图案重新连接 | 使用官方「筑梦拼图」名称；支持连续拿起、拖动、交换、点击换位与旋转，配原创艺术玻璃画。 |
| 黄金替罪羊 | 黑暗记录并复现行动，最终停在机关上；自己点亮祭坛，接触黑暗会失败 | 使用祭坛、持火者与黑暗轨迹记录条；通关目标明确为点亮祭坛，而非普通出口。地图和跌倒机制做了网格化简。 |
| 继电石 | 放电石发出电流，继电石中继，聚电石接收；电流有距离限制 | 使用原作三类机关名称；支持放置和取回、库存限制、距离连通、实时紫色电流与全部聚电石判定。 |
| 熄灯 | 经典 Lights Out 中，每次操作翻转自身与四邻 | 明确标为番外经典逻辑玩法，不冒充原神机关立方的完整规则。 |

## 主要观察资料

- 匣里流光：光线始终存在于场景中，承接器具有真实装置尺度；第二天开始出现带移动标记的机关。[全关卡实机图与攻略](https://www.gamersky.com/handbook/202305/1595400.shtml) · [米游社玩法攻略](https://www.hoyolab.com/article/18738699)
- 溢彩画：公开玩法说明明确写出「点击右侧列表选色，再点击左侧画框涂色」及四邻扩散规则，实机图展示了暗色背景、画框和纵向圆形颜料列表。[溢彩画玩法说明](https://wuthering.gg/zh-Hans/guide/adventure/overflowing-palette) · [换色实机](https://www.youtube.com/watch?v=BiFah4QHR4o)
- 庸人的容器：任务是推开箱子，再与受困者交互；原作采用真实场景中的军械箱和角色，而不是独立抽象棋盘。[任务与实机图](https://www.gamersky.com/handbook/202304/1591179.shtml) · [米游社流程攻略](https://www.miyoushe.com/sr/article/38987555)
- 枘凿六合·Remake：攻略按具体空间位置依次搭建资源块，原版包含普通旋转与 Remake 搭建两种操作。[庙趣满堂实机攻略](https://www.gamersky.com/handbook/202410/1825422.shtml) · [Remake 步骤说明](http://news.17173.com/content/10012024/112111610.shtml)
- 筑梦拼图：匹诺康尼的拼图用于修复画面，并让图案对应的梦境内容成为现实。[2.0 前瞻玩法整理](https://www.miyoushe.com/sr/article/48377230) · [匹诺康尼实机](https://www.youtube.com/watch?v=T3AB6qWPf8s)
- 黄金替罪羊：公开攻略明确描述记录归零、黑暗复现、停在按钮上开辟道路、接触黑暗失败，以及最终点亮祭坛。[玩法步骤与实机图](https://m.ali213.net/news/gl2501/1598883.html) · [黄金替罪羊实机](https://www.youtube.com/watch?v=336CMN7hcX4)
- 继电石：稻妻导电机关由放电石、继电石、聚电石组成，传导距离有限，角色在附带雷元素时也可参与导电；本项目只保留继电石布设。[机关说明](https://news.gao7.com/article/988665-20210719-1) · [继电石实机](https://www.youtube.com/watch?v=Vsjs77FwXMg)

## 表现与交互取舍

- 机关使用 2.5D 场景、真实比例和独立材质，不再把不同玩法统一成换色方格。镜面、箱体、资源块、晶体、画片和祭坛分别渲染。
- 保留可撤销、可重置、可验证的最短解与分级提示。提示不会代替玩家自动完成整关，执行提示仍计入操作数。
- 光线传播、镜面绕轴翻转、染色扩散、箱体推移、角色与黑暗位移、画片拖拽和归位均使用连续反馈；系统减少动态效果设置会关闭这些动画。
- 浏览器短局没有复制原作的角色、剧情、奖励、原关卡、移动机关或全部失败机制。这些简化在玩法目标和操作说明中直接表达，避免用原创术语伪装原作规则。
- 桌面与移动端共用相同规则。键盘、鼠标和触屏均通过实际浏览器验收，320、390、768 像素布局不产生横向溢出。
