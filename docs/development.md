# 开发文档

## 项目结构

- `public/games/` 存放纯 JavaScript 游戏引擎、求解与生成逻辑，`common.js` 提供网格、位掩码、种子随机与 BFS。
- `public/views.js`、`public/extra-views.js` 和 `public/circuit-view.js` 注册玩法文案与场景视图。渲染函数由关卡、状态和交互上下文驱动。
- `public/scene.js` 提供等距投影、金属与石材定义、场景装置和原创角色图形，供各玩法组合独立的 2.5D 场景。
- `public/app.js` 管理路由、关卡切换、输入映射、撤销、重置、分级提示与专属通关反馈。匣里流光在每次旋转后立即校准光路，没有单独的试射状态。
- `public/motion.js` 根据前后棋局状态生成等距位移、镜面转动、染色扩散和画片过渡，并把棋盘点击、拖拽和滑动映射成动作。减少动画设置只影响表现。
- `public/storage.js` 使用 `game-lab.v1` 读取和写入版本化本地存档。固定关卡按游戏和关号保存；每种游戏只保存最近一局随机挑战的进度。
- `public/campaign.js` 保存固定关卡快照，首页渲染无需运行生成器。固定题种子和生成状态同时进入测试。
- `public/sw.js` 缓存运行时资源。部署更换文件内容时递增缓存版本；新增模块时更新缓存列表。打开旧版的页面关闭后，待更新的 Service Worker 会接管后续访问。

## 状态接口

每个引擎导出下列纯函数。状态是可序列化的数字、对象或数组，实例与渲染均无需注入 DOM。调用方可记录 `level + state + action`，重放任意一步，或调用 `solve` 得到最短路线的参考答案。

| 接口 | 约定 |
| --- | --- |
| `actions(level, state)` | 枚举动作候选。移动游戏在边界、碰撞等情况下可能保持原状态。 |
| `reduce(level, state, action)` | 返回下一状态。类型不支持或超界时返回原状态。 |
| `won(level, state)` | 验证当前棋盘是否满足全部过关条件。 |
| `solve(level, state)` | 返回最少动作序列；已过关返回空数组，不可达返回 `null`。 |
| `generate(seed, difficulty)` | 接受无符号 32 位种子和 0–2 的难度，生成包含 `initial` 与最少步数 `par` 的关卡。 |
| `levels()` | 返回稳定固定关卡及其标题。 |

动作详见各引擎。例如匣里流光使用 `{type:'rotate', i:0}`，溢彩画使用 `{type:'paint', i:0, color:1}`，黄金替罪羊使用 `{type:'move', direction:'wait'}`。每次重玩可从 `level.initial` 开始。随机关卡通过 URL 片段携带种子，例如 `#echo/random/2/1375`。修改生成器规则时，应对随机路由和本地存档做对应的版本迁移。

## 求解与难度

| 引擎 | 验证与求解 |
| --- | --- |
| 匣里流光 | 沿网格追踪光束，检测循环，验证沿途传感器与终点。穷举镜向并取最少翻转。 |
| 继电石 | 用距离阈值构图，遍历通电连通分量，穷举可用继电石组合。 |
| 溢彩画 | 位掩码找同色连通区域；用颜色数下界、已搜索状态缓存和迭代加深搜索目标颜色。 |
| 熄灯 | 对空面板做反向 BFS，复用每个尺寸的最短路径表。 |
| 庸人的容器 | 对玩家位置和排序后的箱子点位做 BFS。受阻推挤原路停留。 |
| 枘凿六合·Remake | 将方块掩码投影到三个轴平面，枚举较小的体素空间并按差异位数取最少操作。 |
| 筑梦拼图 | 交换最少次数等于置换的长度减去循环数；各张图的顺时针旋转独立求解。 |
| 黄金替罪羊 | 对当前位置、回声位置、录下的行动和回放游标做 BFS；相撞是终止状态。 |

生成器只接受最短解落在指定区间的初始状态，所有上架题都经由判定器回放。最短动作数是难度下限的估计，人类感受到的难度也受布局与误导路径影响。采用板面尺寸上限保证搜索空间适合短局。溢彩画和黄金替罪羊的规则升级会清除这两款游戏的旧版局面与步数，其余存档可继续使用。用 `gjs -m scripts/export-campaign.js > public/campaign.js` 或 `node scripts/export-campaign.js > public/campaign.js` 更新固定关卡快照。

## 增加一个游戏

新增引擎并在视图注册表提供名称、规则、策略提示、描边提示与渲染。将控件映射到引擎动作，添加可复现的固定种子与难度范围。随后更新关卡快照、Service Worker 缓存清单、引擎和浏览器测试。
